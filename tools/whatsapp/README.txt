Legacy WhatsApp APK (ADB yedekleme için)
=========================================

Yeni WhatsApp sürümleri ADB yedeklemeyi engeller veya şifreli yedek üretir.
Bu klasöre eski bir WhatsApp APK koyun:

  WhatsApp-legacy-backup.apk

Önerilen sürüm: 2.21.24.x veya benzeri (2021–2022, ADB backup destekli)

İndirme kaynakları:
  - APKMirror: https://www.apkmirror.com/apk/whatsapp-inc/whatsapp/
  - Uygulama adı: com.whatsapp

Kullanım:
  1. APK'yı bu klasöre WhatsApp-legacy-backup.apk olarak kaydedin
  2. WhatsApp Aktarım → "ADB başarısız olursa legacy downgrade dene" işaretli olsun
  3. Uygulama otomatik: mevcut APK yedekler → legacy yükler → ADB backup → orijinal APK geri yükler

Not: Downgrade sırasında WhatsApp geçici olarak eski sürüme döner; işlem bitince güncel APK geri yüklenir.
